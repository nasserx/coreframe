# Assets

Purpose: Stores static source assets that are imported by application code.

Belongs here: fonts, icons, images, and other asset files that are part of the frontend source tree.

Must not be placed here: runtime-generated files, public URL assets that belong in `public`, components, business logic, or asset processing code.

Licensing: every third-party asset checked in here must be accompanied by its license file in the same directory. Current inventory: `fonts/tajawal-arabic-{400,500,700,800}.woff2` (Tajawal Arabic subsets) — SIL Open Font License 1.1, `fonts/OFL.txt`.
